Projects

Crisis Command

Hackathon project, GATEWAYS 2026

A multi-agent system for emergency response and resource coordination. Separate agents assess incidents, allocate resources, plan routes and give commands. When something changes, it replans only the affected parts, explains each reallocation and flags decisions that need human approval.

The front end is Next.js with MapLibre GL, and SQLite is the source of truth. A stateless FastAPI and LangGraph backend runs the agents, with a rule-based fallback if the language models are unavailable. The demo covers a 2,000 km² area around Madikeri, Kodagu.

  • Next.js
  • FastAPI
  • LangGraph
  • MapLibre GL
  • SQLite
